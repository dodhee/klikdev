<h2 id="masalah-solusi">Masalah dan Solusi</h2> 

### Masalah
Anda punya Google Sheets yang diisi oleh banyak orang, tapi:
- Data tidak konsisten (typo, format salah)
- Tidak ada notifikasi real-time saat ada perubahan penting
- Sinkronisasi antar sheet dilakukan manual
- Validasi data cuma andalkan Data Validation bawaan Sheets (terbatas)

### Solusi
Script ini memberikan:
- **Validasi Data Kustom**: Regex, cross-check dengan sheet lain, business logic custom
- **Notifikasi WhatsApp**: Trigger otomatis saat ada data tertentu masuk
- **Sinkronisasi Multi-Sheet**: Update otomatis ke sheet lain berdasarkan trigger
- **Logging Aktivitas**: Semua perubahan tercatat dengan timestamp dan user


<h2 id="cara-kerja">Cara Kerja</h2> 

1. **Event-Driven Architecture**: Script berjalan otomatis saat ada `onEdit`, `onFormSubmit`, atau `onOpen`
2. **Validasi Berlapis**: 
   - Layer 1: Format (email, nomor telepon, dll)
   - Layer 2: Business logic (stok cukup? duplikasi?)
   - Layer 3: Cross-reference dengan database eksternal (opsional)
3. **Notification Queue**: Notifikasi tidak langsung dikirim, tapi masuk queue untuk menghindari rate limit
4. **Error Handling**: Setiap error tercatat di sheet log, tidak crash diam-diam

<h2 id="panduan-deploy">Panduan Deploy</h2> 

### Prasyarat
- Akun Google (sudah punya Sheets)
- Node.js v16+ terinstall
- Clasp terinstall: `npm install -g @google/clasp`

### Langkah Deploy

1. **Clone Repository**
```bash
git clone https://github.com/mbah-dody/sheets-automation-engine.git
cd sheets-automation-engine
```

2. **Login Clasp**
```bash
clasp login
```

3. **Buat Project Baru**
```bash
clasp create --type sheets --title "Automation Engine"
```

4. **Konfigurasi**
Edit `src/config.ts`:
```typescript
export const CONFIG = {
  NOTIFICATION_WEBHOOK: "https://api.fonnte.com/send", // Ganti dengan webhook Anda
  TARGET_SHEET_ID: "1abc...", // ID Google Sheets target
  LOG_SHEET_NAME: "ActivityLog"
}
```

5. **Push ke Apps Script**
```bash
npm run build
clasp push
```

6. **Setup Trigger**
- Buka Apps Script Editor: `clasp open`
- Klik Trigger (ikon jam)
- Tambahkan trigger untuk `onEdit`, `onFormSubmit`
- Save

7. **Test**
Edit cell di Sheets, cek log & notifikasi

### Troubleshooting
- **Error "Script tidak berjalan"**: Pastikan trigger sudah diaktifkan
- **Notifikasi tidak terkirim**: Cek API key dan webhook URL
- **Data tidak tersinkron**: Cek permission Sheets (harus Editor, bukan Viewer)

<h2 id="faq">FAQ</h2> 

### Apakah bisa diintegrasikan dengan database eksternal?
Ya, tapi perlu custom. Script ini by default hanya berinteraksi dengan Google Sheets. Jika butuh integrasi ke MySQL/PostgreSQL/Firebase, itu masuk kategori DFY (Done-For-You).

### Berapa batas data yang bisa dihandle?
Google Apps Script punya quota 6 menit execution time per trigger. Untuk data >10,000 rows, saya sarankan pakai batch processing (tidak include di script ini, perlu custom).

### Apakah mendukung multi-user collaboration?
Ya, script ini aman untuk multi-user. Setiap action tercatat dengan email user yang melakukan perubahan.

### Bagaimana cara update script jika ada bug?
Pull update dari repo, lalu `clasp push` lagi. Trigger tidak perlu di-setup ulang.

### Apakah ada dokumentasi API?
Ya, semua fungsi publik ada JSDoc-nya. Buka di Apps Script Editor untuk lihat intellisense.
