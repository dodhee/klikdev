## Masalah & Solusi

### Masalah
Developer menghabiskan waktu berjam-jam crafting prompt yang tepat untuk:
- Generate boilerplate code
- Menulis dokumentasi API
- Membuat unit test
- Code review otomatis

Trial-error prompt membuang waktu produktif.

### Solusi
Library ini berisi prompt yang sudah dioptimasi untuk:
- **Code Generation**: Boilerplate, CRUD, API endpoints
- **Documentation**: JSDoc, README, API specs
- **Testing**: Unit test, integration test, edge cases
- **Code Review**: Security audit, performance analysis

## Cara Kerja

Setiap prompt dirancang dengan struktur:
1. **Context Setting**: Memberikan role dan constraint ke AI
2. **Task Definition**: Instruksi spesifik dan measurable
3. **Output Format**: Template hasil yang konsisten
4. **Examples**: Few-shot learning untuk akurasi tinggi

## Tech Stack

| Teknologi | Fungsi |
|-----------|--------|
| Gemini 1.5 Pro | Model AI yang digunakan |
| Markdown | Format prompt library |
| YAML frontmatter | Metadata setiap prompt |

## Panduan Deploy

### Prasyarat
- Akun Google AI Studio (gratis)
- API key Gemini

### Langkah Deploy

1. **Download Library**
Setelah pembayaran, Anda dapat file `.zip` berisi 50+ file prompt.

2. **Struktur Folder**
```
gemini-prompts/
├── code-generation/
│   ├── crud-api.md
│   ├── boilerplate-express.md
│   └── ...
├── documentation/
│   ├── api-spec.md
│   └── readme-generator.md
└── testing/
    ├── unit-test-generator.md
    └── edge-case-finder.md
```

3. **Cara Pakai**
- Buka file prompt yang relevan
- Copy paste ke Google AI Studio atau API
- Ganti placeholder `[YOUR_CODE]` dengan kode Anda
- Run

4. **Integrasi ke IDE**
(Optional) Gunakan extension seperti Continue.dev untuk pakai prompt langsung dari VSCode.

## FAQ

### Apakah prompt ini work untuk model AI lain (ChatGPT, Claude)?
Sebagian besar ya, tapi ada beberapa prompt yang spesifik memanfaatkan fitur Gemini seperti long context window (1M token). Untuk model lain mungkin perlu sedikit modifikasi.

Ya, selama 6 bulan pertama Anda dapat update prompt baru tanpa biaya tambahan.
